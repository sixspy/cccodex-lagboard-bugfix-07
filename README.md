## 补采重放（回放切断）

回放菜单挂在既有时限台的「补采重放」页，登录沿用回放侧会话，不新开回放台。

- **只走乙路径**：回放行写入同一到达表并贴回放标签（`batch_id`），正式水位、正式到达卡片、
  源目录牌、对账附页一律按标签剔除聚合；剔除失败则标签整段撤销。
- **甲乙互斥**：甲路径（旁路影子库保持正式水位指针原值）不在本仓落库，请求甲或混用即拒绝，
  并记一条「回放切断偏离 / 双计偏了」审计。
- **回放切断卡**：先封板（记封板基准正式水位）再写入，提交后封档；回放当天不许改口。
- **双席同源**：回放席持回放锁（`source_locks`）时，正式补采席后交一律 409 并留「回放双计争用」痕。
- **五处分轨**：回放列表、正式到达卡片、水位读数、源目录牌、对账附页互不并轨。
- 库文件挂回放专卷（compose 具名卷 `lagboard_replay`），封档归档落在 `REPLAY_ARCHIVE_DIR`。

失败测：`tests/test_replay_cutoff.py`（隔离失败测 + 双席抢放失败测 + 清双计/封板/偏离/剔除撤销）。

`

`powershell
python -m pip install -r requirements.txt
